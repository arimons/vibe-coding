# Week 9 — 개인 프로젝트 사양설계서

> **이번 주 목표:** "무엇을 만들 것인가"를 글로 명확하게 정의한다.  
> 코딩 전에 사양을 확실히 잡아두는 것이 프로젝트 성패의 70%를 결정한다.

---

## 왜 사양설계서가 필요한가?

AI와 함께 코딩할 때 가장 흔한 실패 패턴이 있습니다.

> "PDF 넣으면 엑셀로 만들어줘."

이 한 문장으로 시작하면, AI는 **나름대로** 만들어줍니다. 문제는 내가 원한 것과 다를 가능성이 매우 높다는 점입니다. 어떤 PDF? 어떤 항목을 추출? 엑셀 형식은? 파일명은? 폴더 구조는?

구체적인 사양이 없으면 AI도, 나도, 방향을 잃습니다.

사양설계서는 **AI에게 넘기는 설계도**입니다. 잘 작성된 설계서 하나가 수십 번의 수정 대화를 줄여줍니다.

---

## 📋 사양설계서 템플릿

아래 템플릿을 복사해서 본인이 편한 도구(메모장, Notion, Word 등)에 붙여넣고 작성하세요.  
작성이 완료되면 그 내용을 AI 채팅창에 붙여넣어 개발을 시작합니다.

---

### 🎯 Section 1. 문제 정의

**이 섹션이 핵심입니다.** "무엇을 만드느냐"보다 "왜 만드느냐"가 먼저입니다.

---

#### 1-1. 한 줄 요약

> `___` 을 입력하면, `___` 을 자동으로 해주는 도구

*예시: "폴더 안의 COA PDF를 입력하면, 순도·수분·보관조건을 추출해 하나의 엑셀로 정리해주는 도구"*

---

#### 1-2. 현재 상황 (As-Is) — 지금 이 일을 어떻게 하고 있나요?

아래 질문에 최대한 구체적으로 답해보세요.

| 질문 | 내 상황 |
|------|---------|
| 지금은 이 작업을 어떤 방식으로 하고 있나요? | |
| 1회 작업에 시간이 얼마나 걸리나요? | |
| 얼마나 자주 반복되는 작업인가요? (매일 / 매주 / 매월 등) | |
| 이 작업에서 실수가 자주 나는 지점이 어디인가요? | |
| 가장 귀찮고 지치는 단계가 어디인가요? | |

---

#### 1-3. 원하는 상황 (To-Be) — 완성되면 어떻게 달라지나요?

| 질문 | 기대값 |
|------|--------|
| 완성 후 이 작업을 어떤 방식으로 하게 되나요? | |
| 시간이 얼마나 줄어들길 기대하나요? | |
| 이 도구를 혼자 쓰나요, 팀이 함께 쓰나요? | |
| "이것만 되면 충분하다"는 최소 조건이 무엇인가요? | |

---

### 📥 Section 2. 입력 설계

"무엇을 넣는가"를 최대한 구체적으로 묘사합니다.

---

#### 2-1. 입력 데이터 기본 정보

| 항목 | 내용 |
|------|------|
| 데이터 형식 | PDF / Excel / 웹페이지 URL / 기타: |
| 데이터 출처 | 내가 직접 저장 / 메일 첨부파일 / 특정 사이트 / 기타: |
| 1회 처리 단위 | 파일 1개씩 / 폴더째로 / 여러 URL / 기타: |

---

#### 2-2. 입력 데이터 상세 묘사

*아래 질문에 구체적으로 답할수록 AI가 더 정확하게 만들어줍니다.*

**파일 형식이 항상 동일한가요?**

```
예시: 
- 동일함: 우리 회사 COA는 항상 같은 양식입니다.
- 다양함: 거래처마다 표 위치가 달라서 들쭉날쭉합니다.
```

> 내 답변:

---

**데이터가 어느 위치에 있나요? (PDF라면 몇 페이지, 표의 어느 행/열)**

```
예시:
- "1페이지 상단의 제품 정보 표에 모든 데이터가 있습니다."
- "각 파일마다 데이터가 있는 페이지가 달라서 파악이 어렵습니다."
```

> 내 답변:

---

**데이터에 민감 정보가 포함되어 있나요?**

```
예시:
- "거래처명이 포함되어 있어 외부 AI에 통째로 올리기 어렵습니다."
- "공개 정보라 문제 없습니다."
```

> 내 답변:

---

**입력 예시 파일이 있나요?** (실습에 사용할 파일 경로나 특징을 적어주세요)

> 내 답변:

### 📤 Section 3. 출력 설계

"무엇이 나와야 하는가"를 최대한 구체적으로 묘사합니다.

---

#### 3-1. 출력 결과물 기본 정보

| 항목 | 내용 |
|------|------|
| 결과물 형식 | Excel / PDF / 텍스트 파일 / 화면 출력 / 기타: |
| 저장 위치 | 입력 파일과 같은 폴더 / 지정 폴더: / 기타: |
| 파일명 규칙 | 예시: `결과_20250424.xlsx` / 자동생성 / 기타: |

---

#### 3-2. 출력 내용 상세 묘사

**추출 또는 생성해야 할 항목을 모두 적어주세요.**

```
예시:
- 제품명
- CAS번호
- 순도 (% 단위)
- 수분함량 (% 단위)
- 보관조건
- 제조사
```

> 추출 항목:

---

**출력 파일의 형태를 스케치해보세요.** (표라면 컬럼명, 한 행이 무엇을 의미하는지)

```
예시:
| 파일명 | 제품명 | 순도 | 수분 | 보관조건 |
|--------|--------|------|------|---------|
| COA_001.pdf | ... | ... | ... | ... |
```

> 내 스케치:

---

**결과물을 사람이 추가로 손봐야 하나요, 바로 쓸 수 있어야 하나요?**

```
예시:
- "AI가 뽑아주면 내가 한 번 검토 후 제출합니다." → 약간의 오류 허용
- "자동으로 ERP에 들어가야 해서 100% 정확해야 합니다." → 엄격한 형식 필요
```

## ✅ 작성 완료 체크리스트

설계서를 다 작성했다면, 아래를 점검해보세요.

- [ ] 한 줄 요약이 "무엇을 넣으면 무엇이 나온다" 형식으로 완성되어 있다
- [ ] As-Is와 To-Be가 구체적인 숫자나 상황으로 채워져 있다 (막연한 "편해진다" X)
- [ ] 입력 데이터의 형식, 출처, 개수가 명확하다
- [ ] 출력 항목 목록이 구체적으로 나열되어 있다
- [ ] 출력 파일의 형태를 스케치했다
- [ ] 보안·민감정보 여부를 확인했다

```text
- 먼저 "입력 파일 읽기 → 결과 출력" 최소 기능(MVP)부터 만들어줘
```

## 💡 주제별 힌트

주제를 아직 못 정했다면, 수업에서 다룬 3가지 기술을 참고하세요.

### PDF 처리 프로젝트

*이런 상황에 적합합니다*

- 매번 반복해서 읽어야 하는 PDF 문서가 있다 (COA, 보고서, 영수증 등)
- 여러 PDF에서 같은 항목을 뽑아 하나의 표로 모으고 싶다
- PDF 내용을 번역하거나 요약하고 싶다

*핵심 라이브러리: pymupdf, pdfplumber, google-genai*

---

### Excel 처리 프로젝트

*이런 상황에 적합합니다*

- 여러 엑셀 파일을 하나로 합치는 작업을 반복한다
- 엑셀 데이터를 특정 기준으로 분류·정리하고 싶다
- 원본 데이터를 가공해서 보고서용 형식으로 변환하고 싶다

*핵심 라이브러리: openpyxl, pandas*

---

### 웹 스크래핑 프로젝트

*이런 상황에 적합합니다*

- 특정 사이트의 데이터를 주기적으로 수집해야 한다
- 여러 페이지에 흩어진 정보를 하나로 모으고 싶다
- 경쟁사/원료 가격 등을 모니터링하고 싶다

*핵심 라이브러리: requests, beautifulsoup4, playwright*
