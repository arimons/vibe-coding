## pandas 기본 개념

### DataFrame이란?

**DataFrame** = Excel 시트와 같은 2차원 표 구조입니다.

| 용어 | Excel에서 | pandas에서 |
|------|-----------|------------|
| 표 전체 | 시트(Sheet) | DataFrame |
| 가로 한 줄 | 행(Row) | row |
| 세로 한 줄 | 열(Column) | column |
| 한 칸 | 셀(Cell) | 값(value) |

### 핵심 함수 요약

| 함수 | 하는 일 | Excel 비유 |
|------|---------|------------|
| `pd.read_csv("파일명")` | CSV 파일을 표로 읽기 | 파일 열기 |
| `pd.read_excel("파일명")` | Excel 파일을 표로 읽기 | 파일 열기 |
| `df.head(5)` | 처음 5행 보기 | 위에서 5행 선택 |
| `df.shape` | (행 수, 열 수) 확인 | 우하단 셀 주소 보기 |
| `df.columns` | 열 이름 목록 | 첫 행(헤더) 보기 |
| `df.describe()` | 평균·표준편차 등 요약 | 기술통계 함수 |

### 핵심 패턴 3가지

이 3가지만 기억하면 데이터 분석의 80%를 처리할 수 있습니다:

```python
# 1. 열 선택 — 특정 열만 뽑기
df["moisture_val"]

# 2. 행 필터링 — 조건에 맞는 행만 뽑기
df[df["Visit"] == "V1"]

# 3. 정렬 — 값 기준 줄 세우기
df.sort_values("moisture_val", ascending=False)
```

### 그룹별 통계

```python
df.groupby("Visit")["moisture_val"].mean()      # 그룹별 평균
df.groupby("Visit")["moisture_val"].describe()   # 그룹별 요약 통계
```

> `groupby` = "이 열의 값별로 나눠서 계산해줘"
> Excel의 피벗 테이블과 비슷한 역할입니다.

### 결측값

실험 데이터에는 측정 누락, 기기 오류 등으로 빈 칸이 생깁니다.
pandas에서는 이를 **NaN** (Not a Number)으로 표시합니다.

```python
df.isnull().sum()   # 열별 결측값 개수
```

## 정규식 레퍼런스

> Part 1과 Part 2 모두에서 사용합니다. 한 번 익혀두면 어떤 데이터에도 활용할 수 있습니다.

### 정규식이란?

**정규식(Regular Expression, regex)** = 문자열에서 특정 패턴을 찾아 추출하는 도구입니다.

Excel에서는 `MID()`, `FIND()`, `LEFT()` 함수를 여러 개 조합해야 하지만,
정규식으로는 **패턴 한 줄**로 끝납니다.

### 두 가지 모드

**추출 (Extract)** — 패턴에 해당하는 부분만 꺼내기

```
입력: S001_김민지(F/28)
패턴: \(([MF])
결과: F
```

**치환 (Replace)** — 패턴에 해당하는 부분을 다른 값으로 바꾸기

```
입력: 45.2 AU
패턴: \s*AU$    (끝에 붙은 " AU" 제거)
바꿀값: (빈칸)
결과: 45.2
```

### 자주 쓰는 패턴

| 목적 | 패턴 | 입력 예 | 결과 |
|------|------|---------|------|
| 숫자만 추출 | `([\d.]+)` | `45.2 AU` | `45.2` |
| 괄호 안 성별 | `\(([MF])` | `S001_김민지(F/28)` | `F` |
| 괄호 안 나이 | `/(\d+)\)` | `S001_김민지(F/28)` | `28` |
| 언더스코어 앞 ID | `^([^_]+)` | `S001_김민지(F/28)` | `S001` |
| 이름만 추출 | `_([^(]+)\(` | `S001_김민지(F/28)` | `김민지` |
| 방문차수 + 피험자 | `V(\d+)_S(\d+)` | `V1_S12` | `1`, `12` |
| 끝 단위 제거 | `\s*[A-Za-zμ²/h]+$` | `8.3 g/m²h` | `8.3` |

### 기호 설명

| 기호 | 의미 | 예 |
|------|------|---|
| `()` | 이 안의 내용을 추출 (캡처 그룹) | `([\d.]+)` → 숫자 부분 추출 |
| `[\d.]` | 숫자 또는 점 한 글자 | `4`, `5`, `.` 각각 매칭 |
| `+` | 앞 패턴이 1회 이상 반복 | `[\d.]+` → `45.2` 전체 매칭 |
| `*` | 앞 패턴이 0회 이상 반복 | `\s*` → 공백 없어도 매칭 |
| `^` | 문자열 시작 | `^S` → S로 시작하는 경우 |
| `$` | 문자열 끝 | `AU$` → AU로 끝나는 경우 |
| `\(` | 괄호 문자 `(` 자체 (이스케이프) | `\(` → 여는 괄호에 매칭 |
| `[^_]` | `_`가 아닌 모든 문자 | `[^_]+` → `_` 전까지 |
| `\d` | 숫자 한 글자 | `\d` → 1, 2, 3 |
| `\s` | 공백 문자 (스페이스, 탭 등) | `\s*AU` → 공백+AU |

### 패턴 읽는 법 — 예시

```
V(\d+)_S(\d+)     →  "V1_S12"에서 방문차수(1)와 피험자번호(12) 추출
│  │    │  │
│  │    │  └─ 숫자 1개 이상 → 피험자 번호
│  │    └──── 구분자: 언더스코어
│  └───────── 숫자 1개 이상 → 방문 차수
└──────────── V 글자 자체

\(([MF])           →  "김민지(F/28)"에서 성별(F) 추출
 ↑  ↑↑
 |  |└─ M 또는 F 한 글자
 |  └── 이 부분을 추출 (캡처 그룹)
 └───── 여는 괄호 ( 문자
```

### Step 2: 데이터 취합 — 정규식 분리 + 멀티시트 합치기

`🔧 데이터 취합` 탭에서 진행합니다.

#### 정규식으로 피험자 정보 분리

Column C에 `V1_S12` 같은 값이 있습니다:
- `V1` = 1차 방문 (섭취 전)
- `S12` = 12번 피험자

패턴: `V(\d+)_S(\d+)`

```
V(\d+)_S(\d+)
│  │    │  │
│  │    │  └─ 숫자 1개 이상 → 피험자 번호 (12)
│  │    └──── 구분자: 언더스코어
│  └───────── 숫자 1개 이상 → 방문 차수 (1)
└──────────── V 글자 자체
```

앱에서 미리보기를 확인하고, 그룹 라벨(1→섭취전, 2→섭취후)을 설정합니다.

#### Tidy Data — 왜 하나로 합치는가?

**Tidy Data** = 분석하기 좋은 표 구조. 규칙은 3가지:
1. **각 행** = 하나의 관찰값
2. **각 열** = 하나의 변수
3. **각 표** = 하나의 관찰 단위

```
변환 전: 성분별로 시트가 나뉘어 있음
  [cholesterol 시트]  V1_S1 → 0.644
  [C20FA 시트]       V1_S1 → 190.59

변환 후 (Tidy Data):
  Subject | Group  | Component   | Value
  1       | 섭취전 | Cholesterol | 0.644
  1       | 섭취전 | C20FA       | 190.59
```

> 이 형태가 되면 필터링, 통계, 시각화가 전부 한 줄로 됩니다.
> 수동으로 하면 시트마다 복사-붙여넣기를 반복해야 하지만,
> 앱에서는 **시트 선택 → 취합 실행** 버튼 한 번이면 끝입니다.

프롬프트 (AI에게 직접 요청할 때):
```
"Cicca B5_fatty Acid_raw data.xlsx"에는 C20FA~C30FA 6개 시트가 있어.
각 시트 구조는 콜레스테롤과 동일해:
- 처음 6행은 건너뛰기
- Column C = Sample Text (V1_S1 형식)
- Column L = ng/mg protein (측정값)

모든 시트에서 이 두 컬럼만 뽑아서 하나로 합치고,
시트 이름을 Component 컬럼으로 추가해줘.
Sample Text는 정규식 V(\d+)_S(\d+)로 Visit, Subject 분리하고
Visit 1은 "섭취전", 2는 "섭취후"로 변환해줘.
```

**확인할 것:**
- [ ] Component 컬럼에 7개 성분이 다 있는지?
- [ ] 전체 행 수가 대략 `30명 × 2회 × 7성분 ≈ 420행` 근처인지?
- [ ] 빠진 피험자가 있는지? (탈락자)

### Step 3: 통계 처리 — Z-score

`📊 통계 처리` 탭에서 진행합니다.

#### Z-score란?

**Z-score** = 개별 값이 평균에서 표준편차 몇 배만큼 떨어져 있는지를 나타내는 값입니다.

$$Z = \frac{값 - 평균}{표준편차}$$

**왜 필요한가?**

| 성분 | 평균 | 표준편차 | 값 범위 |
|------|------|----------|---------|
| Cholesterol | ~1.3 | ~0.7 | 0.5 ~ 3.5 |
| C20FA | ~270 | ~100 | 80 ~ 500 |

단위가 같은 ng/mg protein이더라도, 값의 스케일이 전혀 다릅니다.
Z-score로 변환하면 **"각 성분 내에서 얼마나 극단적인 값인가"**를 동일한 척도로 비교할 수 있습니다.

| Z-score | 의미 |
|---------|------|
| 0 | 딱 평균 |
| 1.0 | 평균보다 1 표준편차 높음 |
| -1.0 | 평균보다 1 표준편차 낮음 |
| 2.0 이상 | 상위 ~2.5% (이상치 후보) |
| -2.0 이하 | 하위 ~2.5% (이상치 후보) |

프롬프트:
```
각 Component별로 Value의 Z-score를 계산해서 Z 컬럼에 추가해줘.
Component × Group별 평균, 표준편차, 데이터 수도 보여줘.
```

---

### Step 4: 시각화

`📈 데이터 시각화` 탭에서 진행합니다.

#### 어떤 차트를 선택해야 할까?

우리가 보고 싶은 것:
- 섭취전 vs 섭취후 **비교**
- 30명 각각의 **개별 값**
- 전체 데이터의 **분포 형태**

| 차트 종류 | 개별 값 | 분포 | 비교 | 우리 상황에 |
|-----------|---------|------|------|-------------|
| Bar Chart | ✗ | ✗ | ○ | 평균만 보임 |
| Box Plot | △ | △ | ○ | 분포 요약만 |
| Scatter Plot | ○ | ✗ | △ | 두 변수 관계용 |
| Histogram | ✗ | ○ | △ | 빈도 분포용 |
| **Violin Plot** | **○** | **○** | **○** | **딱 맞음!** |
| Paired Plot | ○ | ✗ | ○ | 개인별 전후 변화 |

> **Violin Plot** = Box Plot + 분포 곡선 + 개별 점을 한 번에 보여주는 차트.
> 바이올린 모양을 닮아서 이런 이름이 붙었습니다.

> **Paired Plot** = 같은 피험자의 전후 값을 선으로 연결. 개인별 변화 방향이 한눈에 보입니다.

앱에서 차트 종류, 성분, 색상을 선택하면 바로 그래프가 그려집니다.
Z-score 전환, 전체 성분 비교, 변화율 바 차트도 제공합니다.

프롬프트 (AI에게 직접 요청할 때):
```
섭취전/섭취후를 비교하는 그래프를 그리고 싶어.
- 30명 정도의 개별 데이터 포인트가 보여야 해
- 전체 분포의 모양도 보고 싶어
- 평균값과 오차도 표시되면 좋겠어
어떤 차트가 적합할까?
```

> **바이브코딩 핵심:** 차트 이름을 몰라도 됩니다.
> "분포도 보고 싶고 점도 보고 싶다"라고 설명하면
> AI가 "Violin Plot이 적합합니다"라고 제안해줍니다.
> 정확한 용어보다 **원하는 결과를 묘사하는 능력**이 중요합니다.

## 프롬프트 작성 팁

AI에게 데이터 처리를 요청할 때 이 3가지를 포함하면 정확한 결과를 얻습니다:

| 요소 | 예시 |
|------|------|
| **데이터 구조** | "Column C에 V1_S12 형식의 값이 있어" |
| **원하는 결과** | "Visit과 Subject를 분리하고 싶어" |
| **제약 조건** | "첫 6행은 메타데이터라 건너뛰어야 해" |

```
❌ 나쁜 예: "데이터 분석해줘"
⭕ 좋은 예: "Column C의 V1_S12 패턴에서
            V 뒤 숫자(방문차수)와 S 뒤 숫자(피험자번호)를
            정규식으로 분리해서 새 컬럼으로 만들어줘"
```

> **모르는 용어는 괜찮습니다.**
> 바이브코딩에서 중요한 건 정확한 용어가 아니라, **원하는 결과를 묘사하는 능력**입니다.
